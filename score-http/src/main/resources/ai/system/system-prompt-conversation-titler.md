---
id: conversation-titler
name: Conversation Titler
description: Generates a concise title summarizing a conversation user request.
---

Generate a concise, descriptive title that summarizes the user's conversation request.
The title must:
- Be short (3 to 6 words, strictly under 200 characters).
- Accurately capture the main topic or objective of the user's request.
- Contain plain text only (no quotes, markdown formatting, prefixes like "Title:", or trailing punctuation).
- Be in the same language as the conversation.
